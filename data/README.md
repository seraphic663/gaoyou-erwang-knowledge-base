# 数据与来源

本目录直接保存研究材料层；不再用 `literature/`、`external/` 这样的中间包装目录。原始来源、当前阅读、标注输入、外部语料、旧库和 V2 运行数据的性质仍然分开。

| 入口 | 内容 | 处理边界 |
| --- | --- | --- |
| `0-当前阅读/` | 当前阅读笔记、个案 Markdown、归档 Markdown 和当前案例材料 | 当前研究工作层；按个案和来源链维护 |
| `A-原著原典/` | 四部王氏原典 Markdown | canonical source，默认只读 |
| `B-一级资料/` | 合集、序跋、遗书和补充版本材料 | 来源材料，默认只读 |
| `C-二级资料/` | 研究论文、学位论文、方法论和数字人文参照 | 研究参考，默认只读 |
| `D-标注/` | DOCX、JSON、人工标注和 AI 整理输入 | 历史输入/结构化导入层，不自动成为 gold |
| `scripts/` | 文献转换和标注导入辅助脚本 | 代码入口，改动后需做路径和导入检查 |
| `daizhigev20/` | 殆知阁外部语料、命中分析和外部候选材料 | 外部 evidence acquisition 候选层，不自动成为 canonical |
| `literature.md` | 原典、资料、当前阅读和标注材料的详细目录说明 | 导航说明，不是额外数据层 |
| `external.md` | 外部来源边界和殆知阁目录说明 | 导航说明，不是额外数据层 |

`v2/data/` 保存 V2 运行数据、队列、报告和外部候选包；`solution/legacy-db/data/` 保存旧 SQLite 产物。二者不属于本目录，不手工编辑生产结果。原始文献和生产数据库默认只读；派生快照必须从声明的输入重建。
