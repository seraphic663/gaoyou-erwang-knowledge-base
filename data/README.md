# 数据与来源

> 路径复核于 2026-10-31。各子目录 README 说明具体版本和处理边界。

| 入口 | 内容 | 边界 |
| --- | --- | --- |
| `0-当前阅读/` | 当前阅读笔记和仍在使用的阅读材料 | 不承载已迁移的标注库；原始/历史条目保留其来源身份 |
| `A-原著原典/` | 王氏四部原典 Markdown | canonical 工作文本；默认只读，索引一致不等于底本已校勘 |
| `B-一级资料/` | 合集、序跋、遗书和版本材料 | 来源材料；核校时保留版本信息 |
| `C-二级资料/` | 研究论文、学位论文和方法参照 | 研究参考，不直接当作王氏原典证据 |
| `D-标注/` | DOCX、转写、案例 Markdown、JSONL 和人工标注数据库 | 当前标注处理入口，见 [D-标注 README](D-标注/README.md) |
| `daizhigev20/` | 殆知阁外部文献和命中分析 | 外部检索候选；不自动成为 canonical 或人工证据 |
| `scripts/` | 来源转写与标注导入脚本 | 修改时同步检查子目录说明和生成数据路径 |
| `literature.md`、`external.md` | 数据范围与来源导航 | 导航文档，不是额外数据层 |

V2 运行库位于 `v2/data/real_runs/`；机器库 bundle 位于 `solution/website/runtime-bundle/`；旧 SQLite 位于 `solution/legacy-db/data/`。三者均不应手工编辑。

标注源文件、机器解析、网站快照和 V2 工作库彼此分开。任何页面或转换器的成功返回都不能代替人工确认。
