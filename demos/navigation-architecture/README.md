# 页面架构对照演示

纯本地 Node.js 原型，不依赖数据库或第三方包，不调用模型。当前版依据本次线上 HTML 与跳转脚本核对结果制作；建议版实现工作台优先、统一案例列表与携带案例身份的材料跳转。内容为示例，不代表真实来源记录之间的对应关系。

启动：在此目录执行 `node server.js`，浏览器打开 http://127.0.0.1:3190/ 。仅监听本机回环地址，可通过 PORT 环境变量修改端口。

- 当前版：http://127.0.0.1:3190/current/index.html
- 建议版：http://127.0.0.1:3190/proposed/index.html

当前版保留全站五步释证入口及其本页选案能力，不人为增加原站不存在的跳转障碍。人工标注和 V2 详情仍在原页展开；两个旧入口自动重定向。建议版质量信息单列为辅助演示页，不进入主导航。

演示专用的版本切换、路径记录、返回按钮、底部页面清单不属于模拟的网站架构。审核状态使用 localStorage，路径记录使用 sessionStorage，两版互相隔离。无筛选参数的搜索入口仅展示示例，不执行实际检索。
