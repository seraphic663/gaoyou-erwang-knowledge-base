# 研究工作区

> 当前入口复核于 2026-10-31。

`research/` 保存研究问题、外部来源分析、评测定义和人工案例材料。日期化记录保留研究当时的输入、方法和限制；当前项目状态以 `docs/project/05-当前状态与执行评估.md` 为准。

- `analysis/`：来源/关系统计、parser 和检索分析；先区分机器候选与人工结论。
- `analysis/benchmarks/`：检索层 benchmark 定义，不是端到端考据 gold。
- `external-source/`：外部来源与底本线索，不自动升级 canonical。
- `midterm-pilot/`：少量结构化复核案例的编辑包；当前是否已有确认稿以现场内容为准。

历史中期方案已归档到 `docs/project/archive/`，不要把旧数量或优先级直接作为当前事实。
