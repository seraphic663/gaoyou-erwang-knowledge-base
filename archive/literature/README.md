# 归档文献说明

本目录用于保存项目过程中需要回查的原始文献、扫描件、申报材料和历史工作文件。目录内多数文件体积较大，且可能包含 PDF、DOCX、扫描图、电子签名、原始项目附件、编译产物或第三方文献材料，因此除本 README 外默认不纳入 Git 仓库。

日常整理、标注和网站展示优先使用 `data/`、`solution/legacy-db/` 和 `solution/website/data/` 中的工作副本或导出数据。只有在需要核对版式、页码、扫描图、小字号来源、原始 DOCX 样式、项目申报记录或文献来源时，才回到本目录查验。

## 顶层内容

| 路径 | 用途 |
| --- | --- |
| `data/` | 工作文献区的历史归档副本，包含原著原典、一级资料、二级资料、标注稿和旧 README。 |
| `高邮二王合集_原扫描/` | 《高邮二王合集》各册原扫描 PDF，用于页影、OCR 疑点和版本核对。 |
| `立项申报/` | 立项申报书、通知、附件、签字材料等项目申报归档。 |
| `立项答辩/` | 立项答辩 slide、图片素材、QA、名词解释和相关 LaTeX 源文件归档。 |
| `*_高邮王氏四种本.pdf` | 四种核心原典 PDF，用于文本来源与版式核对。 |
| `训诂学原理_王宁_OCR版.pdf` | 二级参考资料归档，用于术语和方法背景查验。 |

## 当前阅读 DOCX 底本

`04-项目文献/0-当前阅读/` 保存当前阅读材料的归档底本：当前归档区有 12 份 DOCX，其中 2 份位于该目录、10 份位于 `整理标注模版/` 子目录，另有 4 份说明性 Markdown。工作区 `data/0-当前阅读/` 同时维护 `annotation/`、`archive/md/` 等 Markdown，以及按日期保存的新增 DOCX；需要核对字体、分页、批注气泡位置和内部 OOXML 结构时，以 Markdown 中实际链接的归档底本为准。

## 使用规则

1. 不直接从本目录导入网站或主数据库；需要进入工作流的材料应先复制或整理到对应工作目录。
2. 不提交本目录中的 PDF、DOCX、图片、签名、数据库、环境文件、缓存或编译产物。
3. 若本目录新增重要资料，应优先更新本文档的索引说明，而不是放开 Git 忽略规则。
4. 若需要公开数据，应另行制作可分发的轻量样例、结构化导出或来源清单。
