## 同题 PDF/DOCX 对照结论

这些文件不是“完全一致的重复文件”。更准确地说，它们多数是同一著作或同一册的两种形态：PDF 是影印本或原扫描，DOCX 是可检索的整理本、标点本或转写本。抽取结果显示，`高邮王氏四种本` 和 `原扫描` PDF 基本没有可抽取文本，不能直接和 DOCX 做逐字比对；但从题名、册次、页数和整理本内容看，它们对应同一著作或同一册。

### 建议保留原则

- 如果只能保留一个用于日常阅读、摘录、检索、做数据库或写申报书，优先保留 DOCX 或 OCR 版 PDF。
- 如果只能保留一个用于版本核对、页码引用、证明原始版面，优先保留影印 PDF。
- 对本项目当前目标而言，建议本地优先保留 DOCX/OCR 版，影印 PDF 可以转存云盘或归档盘，不建议彻底丢失。
