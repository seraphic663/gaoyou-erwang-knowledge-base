### 正式开工前还需要做的事

1. 建第一批工程文件，而不是继续扩写文档：
   - `annotation_case.v1.schema.json`
   - `passage_builder.py` 或至少 `passages.jsonl` prototype
   - `validate_annotation_case.py`
   - `examples/造舟于河.annotation.json`
   - `examples/平原之隰.annotation.json`
2. 用 1 个 passage prototype 跑通：Markdown -> passage -> quote 定位 -> hash。
3. 用 2 个标注案例跑通：模板 JSON -> validator -> 人工库草表。
4. 开 2-3 人 pilot 标注前，准备一份空白模板和两份示例，不要直接全员铺开。
