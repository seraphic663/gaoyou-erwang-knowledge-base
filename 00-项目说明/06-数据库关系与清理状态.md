> 盘点日期：2026-09-28
>
> 本文件记录当前数据库、网站快照、V2运行资料和外部文献的关系。此次整理只增加说明，不修改任何数据库内容；暂不建立 daizhige_search_index.db。

## 1. 一句话

当前真正的主工作库是 v2/data/real_runs/annotation_v2.db。dictionary.db 是旧机器解析库，annotations.db 是旧人工审校灰度库；两个 JSON 是网站读取的导出快照，不是新的主库。daizhigev20 仍是独立的外部文献层，尚未进入任何数据库。

## 2. 数据流

    旧 source.txt
      -> 旧 parser/importer
      -> 02-数据库/data/dictionary.db
      -> sqlite_bridge.py
      -> 03-项目网站/data/sqlite-snapshot.json
      -> 旧网站

    DOCX / AI JSON / 人工 Markdown
      -> 人工标注导入和归一化
      -> 02-数据库/data/annotations.db
      -> annotation_bridge.py
      -> 03-项目网站/data/annotation-snapshot.json
      -> 人工标注浏览器

    四部王氏原典 + 旧 AI JSON + dictionary.db + 外部候选材料
      -> passage / candidate / legacy adapter / source registry
      -> v2/data/real_runs/annotation_v2.db
      -> V2检索、五步释证和人工审校队列

    daizhigev20 Markdown
      -> 当前仅用于二王书名命中分析
      -> 未来可另建 daizhige_search_index.db
