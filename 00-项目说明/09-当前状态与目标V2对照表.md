## 1. 状态标记

| 标记 | 含义 |
| --- | --- |
| `legacy` | 当前存在，但属于旧链路或旧 schema，不作为 V2 规范 |
| `partial` | 已有一部分实现，但未达到 V2 要求 |
| `planned` | 文档规划了，但当前工作区没有对应实现或产物 |
| `pending` | 需要 OCR、抽样、人工审校或外部依赖确认 |
| `ready-to-build` | 规范已足够明确，可以进入实现 |

## 6. V2 的完成判据

V2 不能仅以“文件生成”作为完成。至少需要同时满足：

1. 四部 Markdown 有统一 `work_key`、标题路径、稳定来源 ID 和显式版本信息；
2. passage 能被稳定生成并被 quote 精确定位；
3. candidate 与旧模板 case 分离；
4. 旧 AI JSON、旧机器库和原文 candidate→AI 路径最终都可回查到同一 V2 case/candidate contract，并保留来源层和再加工类型；
5. schema、quote、offset、enum、模板标签和五步校验可运行；
6. `machine_result` 和 `human_review` 不混写；
7. 至少有一批真正人工确认的 gold cases，才能开展 benchmark；
8. 网站展示能明确区分候选、机器通过和人工审校状态。

目前已经满足“4 部原典完成机器 passage/候选盘点、旧 AI JSON 17 条和旧机器库 815 条进入同一 V2 工作库、815 个旧机器案例的定位/过程字段和 7,120 条证据的 legacy 绑定完成、原文候选入口实际生成 4 条 AI 案例、6,745 条候选壳分 68 批全部可回溯入库、目标定位候选已持久化、三类工作队列和 review_events 事务边界建立、机器/人工状态分离、网站只读验收可用”这一阶段性条件；当前 V2 为 7,581 个案例、6,749 个候选和 13,990 条证据，`review_events=0`、gold=0。《读书杂志》canonical 来源版本已确定，但 100 个外部来源仍未登记独立底本、7,241 条引文仍未完成 canonical quote 核验，人工审校和 gold 集仍未完成，项目应称为“V2 机器入口、统一工作库和人工审校前置队列已跑通”，不能称为“V2 主库或考据结论已完成”。
