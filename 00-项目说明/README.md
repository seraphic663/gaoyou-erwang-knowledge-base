## 当前唯一定位

中期目标不是扩大机器案例数量或完成全库人工审校，而是用少量真实案例完成：

明确复核命题 → AI 五步草稿 → 人工逐步判断 → 修订稿 → 确认版本 → 证据与版本归档 → 固定成果展示。

中期成果名称统一为“考据过程结构化复核案例”。它不是机器草稿，不自动等于精校，也不自动等于 V2 gold。

## 当前数据和审计边界

- 原典、旧数据库、旧 AI JSON 和 V2 生产数据库默认只读；
- 中期文件包是少量案例的唯一编辑源；
- 五步审计记录与正式 V2 review 分开；
- machine draft、uncertain、页面标签和固定展示集都不能直接称为 gold；
- 外部来源待核、secondary citation match 和 full JSON 命中不能写成外部原典已核验。

发生冲突时，先看当前代码和文件，再看 03、04 的规则和 05 的状态；archive/ 只用于追溯。
