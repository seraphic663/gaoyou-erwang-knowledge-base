# 工程与运行方案

> 当前维护入口复核于 2026-09-30。

本目录保存实际代码、服务和旧兼容管线。

- `legacy-db/`：旧 dictionary/annotation 数据库及其重建、导出和迁移工具；保留历史兼容边界。
- `website/`：网站、只读检索、V2 浏览和五步审计入口。
- `../ops/`：容器构建、Node 运行时依赖和 Railway 构建契约；不把部署文件混入网站源代码。
- `../v2/`：当前 V2 工作库代码、schema、验证、测试和运行数据包；由于它有稳定的项目根路径契约，作为独立核心工作包保留在根级。

网站和旧管线不得把机器材料、五步草稿或页面标签直接写成 V2 gold。
