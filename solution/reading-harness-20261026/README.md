## 稳定性处理

旧错误 `step_shape_or_citation_index_invalid` 将步骤顺序、字段和索引问题合并。合成用例复现了单条引用配 `[1]`、步骤有明确字段但顺序不同等失败；没有取得用户原次失败的响应，不能断言现场只有这一种原因。

最终协议为 `reading-harness.collation.v3`：以明确引用 ID 连接步骤与证据；按字段归位五步，兼容已有索引和可明确判断的一基索引；安全剥除单层 JSON 围栏、解包单一 result 对象；未决问题的字符串列表逐项原样拼接为换行文本。无法恢复的回答保留原始响应供查看。无需追加模型请求修格式。

真实验收发现 v1/v2 均将 uncertainties 返回为字符串列表，旧校验因只接受字符串而报错。这是通用字段形状兼容问题，修复未针对题目内容或答案。
