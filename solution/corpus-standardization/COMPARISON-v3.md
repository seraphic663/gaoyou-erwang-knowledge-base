# v3 三方切分对比

## 结论与使用建议

本轮 32 处原文位置的审阅显示，v3 相对 v2 为 **1 处改善、11 处退步、16 处持平、4 处未定**，未能整体改善 v2。复核已发现新增的自序或旧条祖标题错配、引文题头丢失，以及跨条内容混入。现阶段保留 v3 作为实验对比版本；后续检索底座仍建议使用 v2，不把 v3 直接替换为默认版。这是局部切分质量判断，不是检索召回或模型问答效果结论。

v3 结构与样本均已冻结。本轮不在这 32 处上继续调规则；若再改方法，应另抽样复测，并如实列出改善与退步。

## 比较设计

比较同一原文锚点在三套独立发布库中的覆盖片段：v1 固定 600 字窗口（重叠 100 字）、v2 结构版、v3 新结构版。v2 在没有自然边界时回退到 600 字窗口、重叠 100 字；v3 在同类情况下约 600 字顺序硬切、无重叠。因此任何差异不能全归因于标题或跨片关联处理。页面分别展示各列原文件标题、识别的章条候选、检索块、阅读窗口、坐标与长度；更长不自动算改善。

本轮使用固定种子 `20261025`，从二王及外部典籍高／中／低频四组各取 8 个位置，共 32 处、涉及 28 份文件。抽样时排除了旧一轮 32 处位置的同文件 ±5000 Unicode codepoints 范围，以减少位置复用。位置清单见 [positions.json](evaluation/v3/positions.json)。A/B/C 对每个位置重新随机映射三种方法；匿名材料、密钥与最终页面文件分别保存于 `evaluation/v3/run/`。

三位 Luna 对 A/B/C 各评缺条头、断注、正文注释脱离、无关条混入、正文截断五维（`0/1/2/null`），并作三组两两判断，可选持平或未定；母 agent 独立复核后保留初评、复核覆盖和最终判定。**判定对象是锚点所在论述**，不能把相邻段落的完整性当作当前锚点的得失。首批初评曾把 T13 的暖姝三类段、T16 的皮干筋角、T25 的几赋错指向邻段，复核已逐项纠正；T25 尤须注意基线保留几赋全文，而 v3 在当前论述处截断。这说明初评不能直接充当 gold，也不能只看长度或候选标题。章条、角色和关联字段只是算法候选，不是标准答案。评价依据见 [三方标注说明](evaluation/v3/RUBRIC.md)。AI 初评加母 agent 复核**不是人工 gold**，32 处等量分层样本也不代表全库加权表现。[87 份人工校勘案例盘点](evaluation/v3/GOLD-AUDIT.md)中的材料聚焦校勘、训释与证据，并未给出本任务所需的章条、注释、序跋切分边界 gold。
