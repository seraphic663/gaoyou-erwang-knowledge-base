# 网站更新记录

本文件只记录三类变化：页面结构变化、数据库链路变化、对外展示口径变化。不再记录样式微调、检查过程和临时方案。

## 2026-08-30 V2 工作库、审校入口与部署边界同步

- 新增 `v2-database.html` 统一入口，将 V2 案例浏览、待办审校和质量报告分栏呈现；旧 `v2-acceptance.html` 只保留兼容跳转。
- 网站新增 `/api/v2/summary`、案例详情、四类审校任务读取和受控 review 提交接口；写入默认关闭，仅在本地显式设置 `V2_REVIEW_WRITE_ENABLED=1` 时开放。
- V2 页面通过 Python bridge 读取 `v2/data/real_runs/annotation_v2.db`，本地运行要求从“仅 Node.js”调整为“Node.js 18+ 与可执行 Python 3”。
- Dockerfile 现安装 Python 3，并复制网站和 V2 运行代码；`v2/data/` 由 `.dockerignore`/`.railwayignore` 排除，线上数据必须通过受控 volume 或显式路径提供。
- 当前 V2 展示口径固定为 7,581 个机器草稿、7,581 个人工待审、gold=0；机器链路完成不等于考据结论完成。
- Railway 的旧健康接口和 V2 summary 已验证可用；CloudBase 的 V2 volume 与接口仍待单独部署验证。

## 2026-05-15 部署构建配置与文档一致性收束

- Railway 明确改为根目录 `Dockerfile` 构建，CloudBase Run 继续复用同一套容器构建配置。
- 当时的 Dockerfile 只复制根目录 `package.json` 和 `03-项目网站/`，不再引用不存在的根目录 `server.js`；该历史配置已被 2026-08-30 的 V2 运行镜像配置取代。
- 部署说明、迁移说明、根 README、冗余性报告和一致性清单同步更新为当前入口：`npm start -> 03-项目网站/server.js`。
- 网站 README 补齐当前 API：数据库浏览接口、访问计数接口和人工标注 AI 释证接口。
- 标注 JSON 流程说明同步到当前状态：`--import-ai` 已是明确导入开关，`annotation_db/` 只是旧标注库目录。
- 首页“人工标注库”入口改为“实验性功能”悬停菜单，拆分为“人工标注库”和“AI 释证”。
- `annotation.html` 改为纯人工库数据库浏览；新增 `ai-annotation.html` 承接 AI 释证，并支持引用材料逐级展开。

## 2026-05-04 数据库口径与仓库结构收束

- 新增 `annotation.html` 人工标注灰度库入口，读取 `02-数据库/data/annotations.db` 导出的 `annotation-snapshot.json`，作为主数据库之外的工作稿浏览界面。
- 新增 `annotation_bridge.py` 和 `npm run sync:annotation`，将人工标注 SQLite 独立导出为网站快照，不混入主库。
- 全站数据库表述统一为”一个专题数据库，多种浏览视角”，明确字词、案例、证据、著作和片段属于同一 SQLite 主库。
- 首页、数据库页、字词详情页、案例详情页和知识页同步改为”字词索引视角””案例索引视角””同库关联””同库证据”等表述。
- `importer.py`（原 `bulk_importer.py`）改为直接调用 `parser.py` 解析 `source.txt`，不再依赖生成型 `parsed_data.py`。
- 删除并忽略 `parsed_data.py`、空库和 SQLite journal；保留并重新计入必要 Python 脚本，说明数据库可重建链路。
- 根目录冗余性分析报告改为必要性清单，明确哪些必须保留、哪些可删除或迁出 Git。

## 2026-04-09 网站最终展示版

- 首页收束为“研究问题与对象 -> 当前能力 -> 代表性案例 -> 数据库试查入口 -> 流程图与补充信息”的展示结构。
- 代表性案例稳定为《经义述闻·左传下》“造舟于河”，以“发疑 - 设问 - 取证 - 释理 - 结论”展示二王考据过程。
- 首页固定展示少量字词和案例预览，完整浏览任务交给 `database.html`。
- 数据库浏览页补充分页、预设检索、视角切换和结构说明，承担统一数据库浏览入口。
- 流程图资源统一使用 `media/step.png`。

## 2026-04-07 申报书口径联动

- 网站首页与申报书 `v4.2` 口径对齐，突出“高邮二王”“王氏四种”“单条考据案例”“词条 - 案例 - 证据 - 出处”的研究主线。
- 首页流程图从占位改为图片展示，用于说明二王校读和考据判断流程。
- 首页底部申报流程和团队分工降级为补充信息，避免打断学术主线。

## 早期原型阶段摘要

- `v0.1`：完成基础静态首页、项目概述、时间线和团队结构。
- `v0.2`：接入 Node 服务入口，建立页面分发与 API。
- `v0.3`：新增统一检索接口，首页从单一词条预览改为字词和案例并列。

- `v0.5`：`database.html` 从结构说明页升级为数据库浏览页。
- `v0.6`：首页轻量化，完整浏览入口转移到数据库页。
- `v0.7-v0.10`：完成展示站整合、古籍整理视觉系统、全站口径一致性和首页主线收束。
