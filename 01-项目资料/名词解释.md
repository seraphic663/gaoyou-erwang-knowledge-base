## PDF P7 考据结构流程图

据王宁《训诂学原理（增补本）》第 248 页整理，用于说明考据过程的基本环节。

### 重点名词

- 发疑：发现这里有解释不清或说法冲突。
- 设问：把疑问说清楚，变成一个要回答的问题。
- 取证：找材料来证明，不能只凭感觉。
- 释理：说明这些材料为什么能证明这个解释。
- 结论：最后判断哪种解释更对。

## PDF P8 代表案例：“造舟于河”

### 《经义述闻·左传下》

《正义》承认“造舟为梁”是比舟以为桥，却又转训“造”为“至”；二王重新追问：“造”究竟应训为比次，还是训为至？

| 环节 | 内容 |
| --- | --- |
| 发疑 | 李巡、孙炎以“比”释“造舟”，孔颖达转训“造”为“至”，形成歧说。 |
| 设问 | 王氏所要确认的是：“造”在此是否本有“比次”义。 |
| 取证 | 以“造之言曹”“造、次一声之转”为音义证据；并举“薳氏之造”“属车之造”等书证。 |
| 释理 | 以声求义，并用“副倅”“属车”“造舟”诸例互证，使字义、句义、文意相安。 |
| 结论 | 李巡、孙炎所说“比舟”正切“造”义；转训为“至”“作”“诣”“成”皆属望文生训。 |
| 类推 | 此例争点明确、证据层次清楚，适合展示“考据过程如何被结构化”。 |

### 重点名词

- 造舟于河：用来展示“一个字为什么这样解释”的例子。
- 比次：这里指船一只挨一只排列起来。
- 音义证据：通过读音相近来说明意思可能相通。
- 望文生训：只看字面就乱解释，没有足够证据。
- 结构化案例：把一个案例拆成问题、证据、解释、结论几块来保存。

## PDF P9 从考据过程到数据类型

## PDF P10 训诂学内容入库

### 训诂术语的层级落点

| 层级 | 术语 | 系统中的落点 |
| --- | --- | --- |
| 训释对象 | 文意训释 / 词义训释 | 区分句意判断与字词训释，避免把语境解释误作稳定义项 |
| 具体方法 | 形训、声训、义训 | 进入方法标签、释理说明和证据类型 |
| 声音路径 | 因声求义、通假 | 处理音近、字通与异文问题，形成核对事项 |
| 互证原则 | 形音义互求 | 作为同类案例比较和证据互证的观察框架 |
| 误释风险 | 望文生训 | 用于旧说裁断、反证说明和人工循证提醒 |

### 重点名词

- 文意训释：解释一句话整体是什么意思。
- 词义训释：解释某个字或词是什么意思。
- 声训：用读音相近来解释字义。
- 因声求义：先看声音关系，再推意思关系。
- 形音义互求：字形、读音、意思一起看，互相印证。

### 人工标注库

- 保存工作稿、AI 草案和人工循证材料。
- 面向标注检查、证据补充和规则迭代。
- 成熟后再进入主数据库。

技术文件：

`DOCX / annotations.db / annotation-snapshot.json`

核心表述：

成熟成果与研究工作稿分离；人工标注—AI 草案—人工循证—规则迭代形成闭环。

### 重点名词

- 主数据库：放已经比较稳定、可以给网站展示的数据。
- 人工标注库：放还在整理和检查中的材料。
- 网站快照：把数据库导出成一个文件，网站直接读取它。
- 规则迭代：发现标注问题后，修改整理规则，下次按新规则做。

## PDF P15 泛化能力：从材料到平台

### 方法迁移

迁移我们的整理流程：把原文、引文和论述转成可循证的结构，再由界面支持检索、阅读和教学。

### 泛化机制

- 文本：原典、引文、学者论述
- 结构：字段、证据类型、过程步骤
- 界面：检索、详情页、引用展开

### 迁移方向

- 材料：经典注疏争议、出土文献、小学专书
- 平台：考据笔记整理、课堂阅读训练
- 目标：让同类问题可比较、可循证

核心标签：

- 文本结构化
- 过程可循证
- 场景可迁移

### 重点名词

- 泛化能力：这套做法以后也能整理别的材料。
- 方法迁移：学的是整理办法，不是照搬二王的结论。
- 文本结构化：把一段文字拆成原文、引文、证据、结论等部分。
- 过程可循证：别人能看到每一步依据，不只看到结果。
- 场景可迁移：以后可以用于课堂、读书笔记或其他考据资料整理。

## PDF P16 AI 在项目中的运用

### 可以辅助

- 相似案例检索
- 证据片段匹配
- 结构化草稿生成
- 提醒人工循证点

### 不能替代

- 原文与版本核对
- 通假方向判断
- 词义与文意区分
- 最终学术结论确定

### 重点名词

- 相似案例检索：输入一个词或方法，找出类似案例。
- 证据片段匹配：帮忙从材料里找可能有用的句子。
- 结构化草稿：AI 先把材料粗略分成问题、证据、解释等部分。
- 人工循证点：提醒哪些地方必须人再查一遍。
- 不能替代：AI 不能直接决定哪个解释是对的。
