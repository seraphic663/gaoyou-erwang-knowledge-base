# 文档与项目上下文

> 当前维护入口复核于 2026-09-30。

本目录对应研究工作区的文档层，负责当前定位、阶段规划、决策、操作边界、项目管理和交接信息。

- `project/`：当前项目说明、证据边界、V2 契约和状态。
- `management/`：立项、答辩、组会和项目管理资料。
- `operations/`：路径、一致性和迁移检查清单。
- `research-plan.md`：研究方向与中期工作备忘录；它是上下文材料，不是日常操作入口。

原始立项和答辩材料保持历史身份，不根据当前研究定位倒改。工程代码和数据库入口分别见 `../solution/` 与 `../v2/`。
