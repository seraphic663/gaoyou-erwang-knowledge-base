# 数据库关系与清理状态

> 盘点日期：2026-09-30
>
> 本文件只说明数据库、网站快照、V2 运行资料和外部文献的关系。本轮不修改数据库内容，不建立 daizhige_search_index.db。

## 1. 一句话

当前真正的主工作库是 v2/data/real_runs/annotation_v2.db。dictionary.db 是旧机器解析库，annotations.db 是旧人工审校灰度库；两个 JSON 是网站读取的导出快照，不是新的主库。daizhigev20 是独立的外部文献层，尚未进入任何数据库。

V2 是可追溯 corpus、检索和后续 agent 研究的基础设施，但其中的 machine draft 仍不是人工知识、benchmark gold 或 V2 gold。

## 2. 数据流

    旧 source.txt
      -> 旧 parser/importer
      -> solution/legacy-db/data/dictionary.db
      -> sqlite_bridge.py
      -> solution/website/data/sqlite-snapshot.json
      -> 旧网站

    DOCX、AI JSON、人工 Markdown
      -> 人工标注导入和归一化
      -> solution/legacy-db/data/annotations.db
      -> annotation_bridge.py
      -> solution/website/data/annotation-snapshot.json
      -> 人工标注浏览器

    四部王氏原典、旧 AI JSON、dictionary.db、外部候选材料
      -> passage、candidate、legacy adapter、source registry
      -> v2/data/real_runs/annotation_v2.db
      -> V2 检索、五步释证和人工审校队列

    中期人工复核文件包
      -> 确认版本
      -> 固定成果展示
      -> 后续 benchmark-ready 任务候选

    daizhigev20 Markdown
      -> 当前仅用于二王书名命中分析
      -> 未来可另建独立检索层

## 4. 快照和备份

### 网站快照

- solution/website/data/sqlite-snapshot.json 由 dictionary.db 导出，供旧网站读取。
- solution/website/data/annotation-snapshot.json 由 annotations.db 导出，供人工标注浏览器读取。

两者可以重建，但在网站改成自动生成前不能删除或手工编辑。

### 当前备份边界

- tmp/manual-annotation-overwrite-20260925/ 保留。
- tmp/manual-annotation-rename-039-20260927-082234/ 保留。
- v2/data/real_runs/rollback_backups/ 中的 V2 回滚库保留。
- 其他临时测试和旧备份暂不删除；本轮只做说明整理，不改变回滚能力。

## 5. 殆知阁边界

daizhigev20 当前是外部文献库，不是 V2 数据库来源。它包含参与命中分析的文献 Markdown、分析脚本、TSV 和图表。

当前不做以下事情：

- 不把全文导入 annotation_v2.db。
- 不建立 daizhige_search_index.db。
- 不把命中分析自动写成 V2 evidence。
- 不把书名命中自动写成 canonical 外部来源。

未来若建立检索索引，应作为独立、可重建的 evidence acquisition layer，向检索或 agent harness 提供候选上下文。

## 6. 当前取舍

1. V2 作为新功能的唯一主工作库。
2. dictionary.db 暂停扩展，作为旧兼容库保留。
3. annotations.db 继续保留，直到需要的人工材料完成迁移。
4. 网站快照暂时保留，等网站改为自动生成后再考虑删除。
5. 临时库和备份库不进入主数据库清单；本轮不删除，以保留回滚能力。
