# 当前决策记录

> 当前有效取舍复核于 2026-10-31。历史推导保留在带日期的研究记录和 archive 中。

## 研究定位

项目以高邮二王考据材料为案例，把问题、出处、证据作用、推理和未决事项组织为可追踪的论证路径。“可复核”指二王的论证过程能够被重新寻迹，不是简单的原文差异对照。

## 数据和页面

- 网站公开机器库使用四书统一 parser 与持久化 SQLite bundle；字词和案例是同一机器库的两种视图。旧 `dictionary.db` 不参与新建库，也不是自动回退源。
- 人工标注库、网站机器库和 V2 工作库保持独立的来源、ID 和状态。导入、检索或页面展示不得自动改成人工确认。
- 原典检索与 AI 校读实验是研究工具。检索命中不自动变成案例证据；v1/v2 的页面差异不等于质量比较结论。

## 学术确认与统计

- 机器候选、人工撰写的待核案例、结构化复核案例、benchmark-ready case 和 V2 gold 分开表述。
- 讹误、脱讹、误字和通假先定义来源映射、计数单位和审核口径，再报告数量；不同库的类别不得直接相加。
- 人工确认必须保存实际意见、修订依据、确认版本和未决项；结构检查或引用定位通过不能替代学术判断。

## 研究推进

先完成可回查的人工案例，再用这些案例明确 taxonomy 和 benchmark 的质量标准。扩充 parser、AI 或页面之前，先说明其对应的研究问题和验收证据。

立项与答辩中的数量承诺仍按原始文件保存；当前说明不自行合并不同口径。
