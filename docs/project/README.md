## 一句话定位

项目以高邮二王材料为案例，把问题、出处、证据作用、推理和未决状态组织成可追溯、可评价的古籍考据任务。数据库、检索和网站是研究环境；人工确认案例是当前阶段的研究增量；benchmark-ready corpus 和领域化 agent harness 是后续评价路线。

## 三个阶段

1. 基础设施：建立来源、passage、candidate、case、evidence、状态和检索关系。
2. 中期生产：完成少量考据过程结构化复核案例，保存真实人工决定、确认版本、证据链和固定展示。
3. 评价研究：从人工确认材料形成 benchmark-ready corpus，比较普通检索/agent 与领域化 harness。

## 当前共同边界

- machine draft、结构化复核案例、benchmark-ready case 和 V2 gold 是四个不同状态。
- 当前检索 benchmark 只评价 retrieval layer，不等于端到端考据 benchmark。
- 原典、旧数据库、旧 AI 输出和 V2 生产数据库默认只读。
- 中期案例以 research/midterm-pilot/ 文件包为唯一编辑源。
- 五步 AI 草稿和人工审计记录不等于正式 V2 review。
- 外部候选、secondary citation match、legacy-derived passage 和 full JSON 命中不能写成外部原典已核验。
- 申报材料中的“不少于 60 条”和答辩材料中的“不少于 300 条”仍未建立换算关系；中期 pilot 不冒充完成任一数量指标。
